# Got Cat? 🐈

A one-file random cat photo generator. Click **Got cat?** and a fresh cat
appears, pulled live from the internet.

## Cat sources

- [cataas.com](https://cataas.com) — Cat as a Service, free, no API key
- [thecatapi.com](https://thecatapi.com) — automatic fallback

Each click randomly picks a source; if one is down, the other steps in.

## Run it

No build, no dependencies. Either:

- Open `index.html` in any browser, or
- Enable **GitHub Pages** on this repo (Settings → Pages → deploy from
  branch) and visit the URL it gives you.
